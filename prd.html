1. 项目概述

Crown Rush（百级冲级）是以「投注累积经验值 → 逐级升级 → 领取奖励」为核心的长周期留存活动。活动共 100 个等级，等级奖励以现金为主，在 8 个里程碑等级配置限量实体大奖。活动包含两个前台页面与一套运营后台配置能力。

项目说明
活动周期以自然月为一期，示例期 12/01 00:00:00 - 12/31 23:59:59（GMT+8）
目标用户全体已注册真实用户，支持后台配置准入条件
核心指标活跃留存、日均有效投注、活动参与率、实体奖品曝光转化
语言预热页与进行中页均为英文；后台为中文

2.4 系统时序（后端视角）

触发执行方动作
注单结算投注流水服务推送有效投注 → 活动服务折算 EXP、写入流水明细
EXP 变更活动服务比对等级门槛 → 升级 → 生成可领取奖励记录

活动结束活动服务关闭领取入口 → 结算未发放工单 → 归档数据 → 按配置决定 EXP 是否清零

3. 业务规则

3.1 经验值（EXP）

  • EXP = 有效投注额 ÷ 游戏类型流水权重；老虎机 1:1，真人娱乐场 20:1（权重由后台配置）。
  • 仅统计活动周期内、参与游戏范围内的有效投注；取消注单、对冲注单不计入。
  • EXP 实时累计，用户无需报名；跨期是否清零由后台配置。

3.2 等级

  • 共 LV1 - LV100，每级配置累计投注门槛与对应奖励；EXP 达标即自动升级，等级只升不降。
  • 可跨级升级（单笔大额投注可一次提升多级），跳过的等级奖励仍可补领。

3.3 奖励

  • 现金奖励：达成等级后需在活动页手动领取，支持「一键领取现金」批量领取全部已达成的现金等级，领取后即时存入账户余额。一键领取不包含实体奖励等级，实体等级必须在各自条目单独领取并完成物流校验。
  • 实体奖励：绑定 8 个里程碑等级，每个等级含「实体奖品 + 现金」。限量发放，库存为 0 时按钮置灰，先到先得。
  • 提现流水：现金奖励需完成老虎机 1 倍或真人娱乐场 8 倍流水后方可提现。

3.4 风控

如发现对冲、套利、同设备/同 IP 多账号等异常行为，平台有权取消参与资格并回收已发放奖励。实体大奖发放前需人工复核。

5.1 物流信息流程

领取实体奖品时的判定：点击实体奖品「领取」→ 系统判断该账号是否已绑定物流信息。未绑定 → 弹出物流信息填写弹窗，完成填写后进入二次确认；已绑定 → 直接进入二次确认弹窗，展示当前物流信息，用户确认后才真正领取并生成发货工单。二次确认弹窗内提供「联系客服修改」入口，需通过账号手机号验证码校验后方可发起修改。

  1. 用户点击「填写物流信息」；未登录则跳转登录页，登录后返回继续填写。
  2. 弹窗中展示当前账号用户名（不可修改），提示「该物流信息将绑定此账号」。
  3. 提交后物流信息绑定账号，不可再次提交或自行修改；页面入口变为「查看物流信息」。
  4. 如需修改，用户点击「联系客服修改」，需通过账号绑定手机号的短信验证码校验后，由客服在后台代为修改，并记录操作日志。

7. 接口与异常

  • 核心接口：活动信息、用户进度、等级任务列表、领取（单项/一键）、领奖记录、排行榜、物流信息提交与查询、验证码发送与校验。
  • 领取接口需幂等，防止重复领取；实体奖品领取需库存原子扣减。
  • 异常态：未登录、活动未开始/已结束、库存售罄、领取失败、网络异常，均需前端明确提示文案。
